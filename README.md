Практична робота 7.1  
Варіант 1: Система управління студентами

Це консольна програма написана мовою JavaScript для управління списком студентів, яка дозволяє:

- переглядати список студентів;
- додавати нового студента;
- фільтрувати студентів за віком, балом та факультетом;
- сортувати студентів за ім'ям, віком та середнім балом;
- переглядати статистику;
- шукати студента за ім'ям.

Використані технології:

- JavaScript
- Node.js
- Масиви об'єктів
- Методи масивів: filter(), sort(), find(), reduce()

Для запуску проєкту потрібно:

1. Встановити Node.js.
2. Відкрити папку проєкту у VS Code.
3. Відкрити термінал.
4. Виконати команду:

```bash
node app.js
```
